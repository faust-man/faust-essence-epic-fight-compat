# epic-fight compat

Аддон Minecraft Java 1.21.1 для **NeoForge 21.1.219+**, **core 1.5.2**
и **Epic Fight 21.17.3.1**. Устанавливается на клиент и сервер вместе с обоими модами.
Fabric не поддерживается: используемый релиз Epic Fight предназначен для NeoForge.

## Выносливость

Проверки и расход выносливости Epic Fight используют запас core, включая усталость,
истощение, задержку восстановления и льготный период мира. Единицы расхода 1:1.
Обычная регенерация Epic Fight отключена; восстановление от его навыков пополняет
общий запас. Отдельная полоска Epic Fight скрыта. Лимит запаса задаёт core.
Каждая отдельная ударная фаза Epic Fight оплачивается один раз, в том числе промахи,
удары с разбега и в воздухе. Попадание одним взмахом по нескольким целям не увеличивает
стоимость. При нехватке выносливости фаза не наносит урон. Базовая стоимость —
`stamina.attackCost` ядра. Двуручный стиль Epic Fight расходует вдвое больше,
кроме категории SPEAR. Обычные атаки мобов не меняются. Creative/Spectator и
отключённая система выносливости сохраняют исключения core.

Начиная с 1.2.0, одноручное оружие со щитом в другой руке также расходует двойную
базовую стоимость: **2 вместо 1**. Поднимать щит не требуется. Другие предметы
во второй руке надбавку не дают; удары рукой, перчаткой и самим щитом под неё
не попадают. Щиты определяются по возможности `SHIELD_BLOCK`, включая совместимые
щиты других модов. Надбавки за двуручный стиль и щит не складываются.

В Защиту добавлен узел **Слаженный бой со щитом**
(`faust_epic_compat:shield_weapon_mastery`): уровень 5, без дополнительной практики.
Он возвращает расход одноручного оружия со щитом к обычному — **1 вместо 2**.
Навык двуручного хвата в Силе эту надбавку не снимает. Новый узел автоматически
добавляется в существующий конфиг аддона; остальные записи сохраняются.

В Силе появились два узла, по умолчанию уровень 5 без дополнительной практики:

- **Двуручный хват** (`faust_epic_compat:two_handed_mastery`) снимает двойной расход;
- **Экономный кулачный бой** (`faust_epic_compat:fist_mastery`) обнуляет расход взмахов
  пустой рукой и оружием категории FIST (включая перчатку Epic Fight).

Истощение по-прежнему запрещает атаки, в том числе бесплатные. Отдельная стоимость
активных навыков Epic Fight сохраняется; их собственные затраты не являются платой
за взмах. Стандартный отдельный расход базовых комбо Epic Fight отключён, чтобы
не было двойной оплаты. Попадания уже оплаченной фазы не списывают выносливость повторно.

## Навыки

Книги удалены из добычи и творческих вкладок; существующие книги нельзя использовать.
Предмет остаётся зарегистрированным, чтобы старые миры могли безопасно загрузиться.
Изучаемые навыки Epic Fight появляются в деревьях core, клавиша K:

- уклонения и перемещение — Ловкость;
- блоки и парирования — Защита;
- восстановление и выносливость — Телосложение;
- остальные боевые навыки — Сила.

Открытие: уровень 5 соответствующей характеристики, дополнительная практика не требуется.
Первый клик изучает узел core. Повторный открывает штатный экран навыка Epic Fight
с выбором слота. Проверки категории слота, владения узлом и запрет изучения книгами
выполняются на сервере; cooldown замены Epic Fight сохраняется.
Для пассивных навыков доступны ровно **три стандартных слота** (PASSIVE1–PASSIVE3).
Остальные категории сохраняют свои штатные слоты: три — это лимит пассивов,
а не общий лимит вместе с уклонением и блоком. Повышение gamerule maxPassiveSkills
не открывает дополнительные места. Слоты 4–16 скрыты из выбора и запрещены сервером;
ранее установленные туда навыки снимаются.
Ранее экипированные навыки без открытого узла снимаются. После revoke узла
навык также снимается. Встроенные атаки, оружейные навыки и вставание не требуют узлов.

Узлы аддона автоматически размещаются сеткой по четыре в ряд с шагом 32 GUI-пикселя
ниже существующих узлов ветки. Вручную заданные позиции сохраняются.

`config/faust-epic-compat/abilities.json` создаётся при запуске сервера, включая
одиночную игру. Это записи Balance.Ability ядра: можно менять skill, level, counter,
amount, parent, requiresAll, requiresAny и excludes. После правок перезапустите сервер.
ID узла: `faust_epic_compat:epicfight/roll`, эффект `faust_epic_compat:skill`.
Не меняйте ID/эффект при балансировке. Для ручной раскладки добавьте такие ID
в `config/faustcore/trees.json`. Отсутствующие позиции аддон заполнит сеткой.
При обновлении до 1.1.0 два новых узла Силы добавляются в существующий файл автоматически,
остальные записи сохраняются. При обновлении сторонних наборов навыков добавьте их узлы в конфиг; существующий
пользовательский файл автоматически не перезаписывается.

## Сборка и проверки

JDK 21. Сначала соберите соседний `../core` версии 1.5.2 через его Wrapper.
Зависимость ядра берётся из `../core/neoforge/build/libs/`; Epic Fight — из
[Modrinth Maven](https://epicfight-docs.readthedocs.io/API/Starting/).

```powershell
./gradlew.bat build
./gradlew.bat runClient
./gradlew.bat runServer
./gradlew.bat runServer -PruntimeChecks
```

JAR: `build/libs/faust-epic-fight-compat-1.21.1-1.2.0.jar`.
`build` запускает 96 проверок распределения, правил оплаты, слотов и компактной раскладки.
`runServer -PruntimeChecks` дополнительно запускает 42 проверки на игровом сервере:
настоящие предметы Epic Fight (двуручный меч, копьё, перчатка), оба узла, недостаточный
запас, истощение, три слота и отсутствие повторной оплаты при обработке целей.
Также проверяются меч со щитом, навык Защиты, независимость от навыка Силы,
недостаток выносливости для надбавки, факел во второй руке и миграция нового узла.
Тестовый игрок не сохраняется; сервер штатно останавливается после проверок.
Этот набор исключён из выпускаемого JAR. Проверки не заменяют ручной прогон всех
анимаций и визуального выбора слотов. Ранее захват окна Computer Use дважды
завершился таймаутом; полный ручной прогон интерфейса остаётся невыполненным.

Исходники Epic Fight использованы для проверки API; его код и ресурсы в аддон
не включаются. Исходная лицензия шаблона Wrapper сохранена в LICENSE.
